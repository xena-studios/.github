# Getting help

- **How do I…?** Start with the project's docs: [docs.raptorpanel.net](https://docs.raptorpanel.net) for Raptor, [docs.xenastudios.co](https://docs.xenastudios.co) for the plugins. NeoSkript and MostWanted are still in development.
- **Bugs and ideas:** open an issue on the project's repo.
- **Security problems:** follow the [security policy](https://github.com/xena-studios/.github/blob/main/SECURITY.md), never a public issue.
- **Anything else:** [contact@xenastudios.co](mailto:contact@xenastudios.co).
