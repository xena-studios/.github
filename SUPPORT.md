# Getting help

- **How do I…?** Each project's README, and its docs: [raptorpanel.net](https://raptorpanel.net) for Raptor, [docs.xenastudios.co](https://docs.xenastudios.co) for the plugins.
- **Bugs and feature requests:** open an issue on the project's repository. Include the version or commit, what you did, and any errors.
- **Security problems:** see the [security policy](https://github.com/xena-studios/.github/blob/main/SECURITY.md). Never a public issue.
- **Anything else:** email [contact@xenastudios.co](mailto:contact@xenastudios.co).
