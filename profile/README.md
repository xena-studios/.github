We build tools for running game servers on your own hardware, the Minecraft plugins that run on them, and Minecraft servers of our own. The tools and plugins are open source.

## Raptor

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://cdn.jsdelivr.net/gh/xena-studios/brand@1/raptor/logo-dark.png">
  <img src="https://cdn.jsdelivr.net/gh/xena-studios/brand@1/raptor/logo-light.png" alt="Raptor" height="48">
</picture>

**Your machine. Every game.**

Run one install command on any Linux box you own or rent, then pick from 350+ games and apps and manage them from the web, with no panel to host. Plugins, mods, modpacks, the Steam Workshop, encrypted backups and databases are built in, and Pterodactyl eggs work as they are.

[Website](https://raptorpanel.net) · [Docs](https://docs.raptorpanel.net) · [Source](https://github.com/xena-studios/raptor) · AGPL-3.0

## NeoSkript

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://cdn.jsdelivr.net/gh/xena-studios/brand@1/neoskript/logo-dark.png">
  <img src="https://cdn.jsdelivr.net/gh/xena-studios/brand@1/neoskript/logo-light.png" alt="NeoSkript" height="80">
</picture>

**Keep your scripts. Lose the lag.**

A fast, modern drop-in replacement for Skript. Your `.sk` scripts run unchanged, only faster, on Paper and Folia. In public beta.

[Website](https://neoskript.dev) · [Docs](https://neoskript.dev/docs) · [Modrinth](https://modrinth.com/plugin/neoskript) · [Source](https://github.com/xena-studios/neoskript) · GPL-3.0-only

## Xena Tools

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://cdn.jsdelivr.net/gh/xena-studios/brand@1/tools/logo-dark.png">
  <img src="https://cdn.jsdelivr.net/gh/xena-studios/brand@1/tools/logo-light.png" alt="Xena Tools" height="48">
</picture>

**Tools for running a Minecraft server.**

Free web tools for server owners: gradient text in every format plugins read, a MiniMessage, legacy and JSON converter, and next MOTDs, startup flags, log analysis, server status and player lookup. Everything runs in your browser, and the link keeps your settings. In development.

[Website](https://tools.xenastudios.co) · [Source](https://github.com/xena-studios/tools) · AGPL-3.0
